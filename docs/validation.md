# 1.0.0 验证记录

验证环境：Windows 11 x64，.NET Framework 系统运行时。2026-10-18 至 2026-10-19。

- 本地编译成功，不依赖额外 NuGet 包或 SDK。
- 37 项测试通过，覆盖分层边界、协议解析、响应校验、无编号 HID feature 的长度计数、69 个雷蛇配置及演示数据标记。
- 实际 USB 查询：Razer DeathAdder V3 Pro (`1532:00B7`) 返回电量及充电状态；测试期间随充电从 92% 更新至 99%。此信息为开发验证结果，不是软件中预设的数据。
- 实际 UI 检查：演示模式的设备选择可切换主展示设备；圆环与闪电交替显示；设置面板可正常打开；退出按钮正常结束进程。
- 预览图由应用自身的 WPF 视觉树渲染生成，显著标注为演示数据。
- 本机未检测到 G435 接收器，没有 G435 LIGHTSPEED 或蓝牙实机验证结果。蓝牙 HFP 读取路径已编译并执行，但没有可用耳机电量样本。
- 其余罗技/雷蛇型号未逐台实测，不能将配置表或协议测试视为硬件兼容性保证。

后续建议验证：真实罗技接收器与多槽位设备、休眠/唤醒/拔插、多显示器不同 DPI、重启 Explorer 后图标恢复、长时间运行的资源占用。当前版本使用 WinForms NotifyIcon 提供 Explorer 图标恢复基础行为，尚未专门执行 Explorer 重启测试。
